# Мой кинозал

Front-end проект на JavaScript без фреймворков.

## Что реализовано

- Приветственная страница с вводом имени.
- Главная страница с приветствием: «Добро пожаловать в кинотеатр, <Имя>!».
- Поиск фильмов и сериалов.
- Отображение результатов карточками или списком.
- Сортировка по рейтингу, дате выхода и названию.
- Фильтр по жанрам.
- Кнопка «В избранное» с сохранением в LocalStorage.
- Модальное окно с подробной информацией о фильме или сериале.
- Отдельные JS-модули: API, модель данных, LocalStorage, отрисовка, утилиты, приложение.

## Как сделана работа без VPN

Проект использует каскадную загрузку данных:

1. Сначала пробует загрузить данные через OMDb API напрямую.
2. Если OMDb не открывается в регионе, пробует OMDb через публичный прокси.
3. Если OMDb недоступен полностью, использует TVMaze API без ключа.
4. Если внешние API не отвечают, показывает встроенный каталог.

За счёт этого сайт не ломается и остаётся рабочим даже без VPN.

## Как запустить

1. Откройте папку проекта в VS Code.
2. Установите расширение Live Server.
3. Запустите `index.html` через Live Server.

Можно также открыть `index.html` напрямую в браузере, но через Live Server модульные JS-файлы работают стабильнее.
